# Airban Converter v0.4.4-beta.1

Release stage: Internal beta

## Interface Polish

- Combined the Results and Conversion Review areas into one compact Output panel.
- Reworked the main page into a cleaner two-column workbench with a sticky map preview on desktop.
- Reduced visual weight in the CSV batch section so it reads as a secondary workflow.
- Tightened spacing, shadows, and responsive behavior for a less cluttered beta testing experience.

## Note

This release focuses on usability and visual hierarchy. Coordinate conversion behavior remains unchanged from `v0.4.3-beta.1`.
