# Airban Converter v0.40.0-beta.1

This beta refines the generated History of Survey wording.

## Added / Changed

- The first History paragraph now reads as a parcel narrative: `at [locality] in the [district]`.
- The GNSS paragraph now states that the reference CORS was used to coordinate the constructed pillars.
- The default boundary wording now ends with `cardinal North`.
- Regression coverage added for the requested Kasoa / Awutu Senya DISTRICT example wording.
