Install Airban Converter

Desktop

Open the HTTPS app URL in Chrome or Edge. Use the address-bar install icon, or press this Install button when the browser offers the app prompt.

Android

Open the HTTPS app URL in Chrome. If there is no install icon, use the three-dot menu and choose Install app or Add to Home screen.

iPhone

Open the HTTPS app URL in Safari. iOS does not show a browser install icon; tap Share, then Add to Home Screen.

Do not install from a downloaded `index.html` file or zip preview. Once installed from HTTPS, coordinate conversion and CSV tools can run after the first app load. The online map basemap still needs internet unless offline map tiles are added later.
