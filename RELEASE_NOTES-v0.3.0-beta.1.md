# Airban Converter v0.3.0-beta.1

Release stage: Internal beta

## Highlights

- Ghana National Grid to WGS84 conversion
- WGS84 to Ghana National Grid conversion
- DMS to decimal degrees parser
- CSV batch conversion for headered and no-header files
- Unit selection for Gold Coast foot, metre, and international foot
- Map preview with all CSV points and visible point IDs
- CSV download with Excel-friendly encoding
- GeoJSON export for plotted points
- Copy action for single-point conversion results
- PWA install support
- Airban Engineering branding with improved header logo

## Beta Notes

- Use this release for controlled testing with known control points.
- Do not treat results as final for cadastral, legal, or high-precision survey deliverables until additional validation is complete.
- The next major hardening step is backend validation with `pyproj`.

## Suggested Tester Group

Start with 3 to 5 trusted colleagues before wider sharing.
