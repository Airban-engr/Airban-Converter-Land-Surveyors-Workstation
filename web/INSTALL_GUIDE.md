# Airban Converter Install Guide

Version: `0.41.1-beta.1`

## Correct Link

Use the hosted HTTPS app URL, preferably ending at the app folder, for example:

```text
https://your-domain.example/airban-converter/
```

Do not open or share:

- `index.html` from the phone Files app
- A zip preview
- An email or WhatsApp attachment preview
- A `file://` URL

## Desktop Browser

1. Open the deployed Airban Converter URL in Chrome or Microsoft Edge.
2. Choose the browser install icon in the address bar if it appears, or press the in-app Install button.
3. Reopen Airban Converter from the desktop shortcut, Start menu, or app launcher.

## Android

1. Open the hosted HTTPS URL in Chrome.
2. If no install icon appears, use the three-dot browser menu and choose Install app or Add to Home screen.
3. Launch Airban Converter from the home screen.

## iPhone or iPad

1. Open the hosted HTTPS URL in Safari.
2. Tap Share.
3. Choose Add to Home Screen.
4. Launch Airban Converter from the home screen.

## Notes

- Serve the app over HTTPS for real mobile installation.
- iPhone and iPad Safari do not show a Chrome-style install icon.
- Conversion and CSV tools can run after the first load because app shell files are cached.
- The OpenStreetMap basemap needs internet unless offline map tiles are added in a later release.
