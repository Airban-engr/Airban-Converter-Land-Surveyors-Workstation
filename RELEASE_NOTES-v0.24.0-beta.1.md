# Airban Converter v0.24.0-beta.1

## Added

- Survey Package Manifest export from the Parcel Workstation.
- Manifest sections for Package Review, Computation Summary, Field Notes and Evidence, Recommended Export Set, Boundary Course Review, Quality Control, and History of Survey.
- Manifest evidence for parcel coordinate source, observation import, observation header mapping, traverse reduction, Bowditch adjustment, area, perimeter, and QC status.

## Updated

- Parcel export controls now include a Manifest button after the branded report export.
- Beta test guide, deployment checklist, feedback template, and web docs now include manifest testing.
- Service-worker cache version bumped for a clean PWA refresh.

## Notes

- The manifest is a human-readable Markdown handoff document. It does not replace the survey workbook, branded report, KML, DXF, GeoJSON, or formal cadastral checks.
